# SXAR Radio Directory v8

The radio directory now supports:
- Search
- Zambia / International filters
- Favorites saved locally
- Now Playing station metadata
- Direct stream playback where a stream URL has been verified
- Official station website fallback where SXAR does not have a verified direct stream

The Zambia radio directory is based on stations listed by the Independent Broadcasting Authority of Zambia. The IBA lists 100 operational radio content service providers, including Radio Phoenix, Hot FM, Sun FM, Live FM, QFM, Power FM, Joy FM, Sky FM and Chikuni Radio.

Radio Phoenix has a direct stream URL included in this prototype. Other station stream endpoints should be added only after verifying them and respecting the station's streaming/licensing terms.
